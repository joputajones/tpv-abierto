# Prueba humana del comprobador de copias

Entrega al evaluador una copia sintética válida y otra alterada. No expliques
los resultados ni uses vocabulario técnico. No entregues datos reales.

## Instrucción para el evaluador

1. Abre FloCafe y busca la herramienta para comprobar una copia.
2. Comprueba la copia válida.
3. Explica con tus palabras qué significa el resultado.
4. Guarda el informe donde puedas encontrarlo.
5. Comprueba la copia alterada.
6. Explica qué harías después de ver el resultado.
7. Señala cualquier palabra o paso que no hayas entendido.
